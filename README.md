# Zenith-Mirror

Resource-efficient, fast Telegram MTProto mirror & leech stream bot built in Go.

## Features
- **/mirror**: Download Telegram media (MTProto, up to 2GB+) & pipe directly to Google Drive.
- **/leech**: Download via HTTP/URL & send to Telegram chat.
- Live progress & task reporting.

## Prerequisites
- Go 1.22+
- Telegram App API ID & API Hash (my.telegram.org)
- Google Drive Service Account JSON
